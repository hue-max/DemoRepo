Add User Data Script while launching Instance in WebServer1
Go to down In Advanced Details → User data section, paste this script:

#!/bin/bash
# Update packages
yum update -y

# Install Apache
yum install -y httpd

# Start Apache
systemctl start httpd
systemctl enable httpd

# Create a test web page
echo "<h1>Welcome to My AWS Web Server1</h1>" |sudo tee /var/www/html/index.html
